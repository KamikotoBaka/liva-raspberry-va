# Mosquitto Password File (optional)
# 
# Format: username:password_hash
# 
# To enable password authentication:
# 1. Uncomment the password_file line in mosquitto.conf
# 2. Generate password hash: mosquitto_passwd -c mosquitto_passwords.txt <username>
# 3. Restart mosquitto
# 
# Example:
# liva_user:$7$123456789012345678901234567890123456
# 
# For now, anonymous access is enabled in mosquitto.conf
